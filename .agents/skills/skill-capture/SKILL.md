# Skill Capture Guidelines

- Identify new recurring patterns, local rules, or integration paradigms that emerge.
- Create a short, focused skill under `.agents/skills/<name>/SKILL.md`.
- Keep skill files concise (under 40 lines) and load-bearing, documenting rules rather than background/history.
- Expose precise trigger paths or file scopes in frontmatter descriptions.
